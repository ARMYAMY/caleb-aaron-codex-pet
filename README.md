# Caleb&Aaron — ChatGPT / Codex Desktop Pet

Aaron、Caleb 和一只戴粉色波点围巾的白色小犬组成的 3D Q 版桌面伙伴。

- Aaron：黑色蓬松短发、深蓝上衣，位于左侧。
- Caleb：酒红色中分短发、水洗牛仔夹克，位于右侧。
- 白犬：蓬松白毛、尖耳、黑鼻，位于前方中央。
- 图集版本：v2，`1536 × 2288`，`8 × 11` 网格，每格 `192 × 208`。

![全部动作预览](preview/all-states.gif)

## 安装

### 方法一：下载图集

1. 下载仓库根目录的 [`spritesheet.png`](spritesheet.png)。
2. 打开 ChatGPT/Codex 桌面应用的 **Settings → Pets**。
3. 选择上传自定义宠物，并使用 `spritesheet.png`。
4. 选择 **Caleb&Aaron**，然后输入 `/pet` 显示悬浮宠物。

需要支持 v2 宠物图集的较新桌面应用版本。网页端、IDE 扩展和终端宠物的交互能力可能不同。

## 动作与触发方式

宠物动作主要由聊天状态自动控制，不是每个动作都有独立的手动播放按钮。

| 动作 | 画面内容 | 触发方式 |
| --- | --- | --- |
| 待机 `idle` | Aaron、Caleb 站在白犬身后，轻微眨眼、呼吸和靠近 | 没有正在运行、等待处理或待查看的聊天时自动播放；鼠标位于宠物中心死区时也会回到待机 |
| 向右移动 `running-right` | 三个角色一起朝屏幕右侧奔跑 | 悬浮宠物向右移动时由客户端调用，通常在拖动或重新定位宠物时出现 |
| 向左移动 `running-left` | 三个角色一起朝屏幕左侧奔跑 | 悬浮宠物向左移动时由客户端调用，通常在拖动或重新定位宠物时出现 |
| 挥手 `waving` | Caleb 挥手问候，Aaron 和白犬陪在身边 | 问候或吸引注意时由客户端选择；当前没有稳定的单独手动触发按钮 |
| 举高高 `jumping` | Caleb 抱起 Aaron，三者一起跃起，随后落回原位 | 玩耍或跳跃反馈时由客户端选择；当前没有公开、稳定的单独手动触发命令 |
| 失败/阻塞 `failed` | Caleb 抱住 Aaron，白犬在旁边陪伴 | 某个聊天失败、被阻塞或遇到系统错误时自动播放 |
| 等待输入 `waiting` | Caleb 抱住 Aaron，白犬在旁边陪伴 | 某个聊天等待你的回答、授权、批准或其他决定时自动播放。可发送“请先问我一个问题，等我回答后再继续”进行测试 |
| 工作中 `running` | 两人专注思考或处理任务，白犬在中间等待 | 聊天正在执行任务、调用工具或处理中时自动播放 |
| 完成待查看 `review` | Caleb 亲吻 Aaron 的脸颊，白犬开心地看着 | 任务已经完成，并存在尚未查看的结果时自动播放 |
| 十六方向视线 `look` | 两人和白犬从上方开始，按顺时针转向 16 个方向 | 仅在桌面悬浮宠物处于空闲状态时生效。将鼠标放在宠物附近并围绕它移动；指针回到中心死区时恢复待机 |

多个聊天同时有状态时，应用通常按 **等待输入 → 阻塞 → 完成待查看 → 工作中** 的顺序显示优先级更高的动作。

### 测试抱抱

1. 输入 `/pet` 显示悬浮宠物。
2. 新建一段聊天并发送：`请先问我一个问题，等我回答后再继续。`
3. 当聊天等待你的回答时，应播放抱抱动画。

![等待输入时抱抱](preview/waiting-hug.gif)

### 测试亲亲

1. 让一个任务正常执行完毕。
2. 保持结果处于未查看或等待你检查的状态。
3. 宠物进入完成待查看状态后，应播放亲亲动画。

![任务完成时亲亲](preview/completed-kiss.gif)

### 测试鼠标视线跟随

1. 确认没有工作中、等待输入、失败或待查看的聊天状态覆盖待机。
2. 把鼠标移到宠物身体外围，在上、右上、右、右下、下、左下、左、左上方向缓慢画圆。
3. 宠物会按 16 个方向切换眼睛、头部和少量身体朝向。
4. 如果没有动画，请关闭操作系统的“减少动态效果”，然后隐藏并重新显示宠物。

## 状态说明与限制

- ChatGPT Pets 的公开说明会随桌面应用版本更新；客户端可能调整装饰性动作的播放时机。
- `waving` 和 `jumping` 没有公开、稳定的独立触发按钮，因此 README 不保证通过一次点击必然播放。
- 当系统启用“减少动态效果”时，宠物可能只显示静态帧。
- 官方使用说明：[ChatGPT Pets](https://learn.chatgpt.com/docs/pets)。
